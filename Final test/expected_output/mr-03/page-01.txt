पीक उत्पादन तंत्रज्ञान षिफारिी

शेती पिके (िीक सुधारणा व तंत्रज्ञान व्यूहरचना)
१. रब्बी ज्वारीचा फुले रेवती हा अधिक िान्य उत्पादन देणारा वाण महाराष्ट्र राज्यातील बागायत क्षेत्रात
भारी जधमनीत लागवडीसाठी धिफारस करण्यात येत आहे.

नैसर्गिक साधनसंित्ती व्यवस्थािन
कृपि हवामानशास्त्र
२. वाांग्यावरील पाांढऱ्या मािीच्या प्रादुभावाची हवामान घटकावर आिाधरत (एक आठवडा आिी)
पुववसूचना देण्यासाठी खालील प्रधतगमन सुत्राची पश्‍चचम महाराष्ट्रासाठी धिफारस करण्यात येत आहे.
सूत्र:
वाांग्यावरील पाांढरी मािी (सांख्या) = -२६.३१३ + (१.०४२ x कमाल तापमान) - (०.८७१ x वाऱ्याचा
वेग) + ( ०.०४ x बाष्ट्पीभवन) + ( ०.३४८ x प्रखर
सूयवप्रकािाचे तास)
याधठकाणी,
पाांढरी मािी               = पाांढऱ्या मािीची सांख्या/पान/झाड (सूत्रामध्ये),
कमाल तापमान           = (२५.०-३२.४ अांि से.),
वाऱ्याचा वेग              = (०.८-४.० धकमी/तास),
बाष्ट्पीभवन                 = (४.१-५.४ धममी),
प्रखर सूयवप्रकािाचे तास   = (३.३-९.३ तास धदवस-१).
३. धमरचीवरील फुलधकडीच्या प्रादुभावाची हवामान घटकावर आिाधरत (एक आठवडा आिी) पुववसूचना
देण्यासाठी खालील प्रधतगमन सुत्राची पश्‍चचम महाराष्ट्रासाठी धिफारस करण्यात येत आहे.
सूत्र:
मिरचीवरील फुलधकडींची सांख्या = -३४.७५७ + (१.१८२ x कमाल तापमान) - (१.२५५ x धकमान
तापमान) + ( ०.४२६ x सकाळची सापेक्ष आर्द्वता) + ( ०.१२ x
सांध्याकाळची सापेक्ष आर्द्वता) - (०.०१५९ x वाऱ्याचा वेग) +
(०.७०७ x प्रखर सूयवप्रकािाचे तास)
याधठकाणी,
फुलधकडे                           = फुलधकड्ाांची सांख्या/पान/झाड (सूत्रामध्ये),
कमाल तापमान                     = (२७.६-३२.४ अांि से.)
मिमान तापमान                    = (८.६-२२.७ अांि से.)
सकाळची सापेक्ष आर्द्वता           = (५६.०-८१.६ टक्के)
सांध्याकाळची सापेक्ष आर्द्वता        = (२८.०-६२.४ टक्के)
वाऱ्याचा वेग                       = (०.४-४.५ धकमी/तास)
प्रखर सूयवप्रकािाचे तास            = (३.५-९.५ तास धदवस-१)
